# 📊 Excel Sales Performance Analysis

## Project Overview

This project demonstrates how Microsoft Excel can be used to analyse sales performance, evaluate profitability, and support business decision-making.

The analysis uses a fictional dataset of 300 sales transactions from 2025.

**Project type:** Business Analysis
**Tool:** Microsoft Excel
**Dataset:** Synthetic sales transactions

## Business Problem

Management needs to understand sales performance across geographical regions, product categories, and sales channels to identify opportunities for improvement.

## Project Objectives

* Analyse total revenue and profit.
* Compare sales performance across regions.
* Evaluate product category profitability.
* Compare online, retail, and corporate sales channels.
* Validate data quality and financial calculations.
* Develop evidence-based business recommendations.

## Excel Skills Demonstrated

| Skill             | Application                                            |
| ----------------- | ------------------------------------------------------ |
| Excel formulas    | Calculate revenue, costs, profit, and profit margins   |
| PivotTables       | Summarise performance by region, category, and channel |
| XLOOKUP           | Retrieve product information                           |
| Data validation   | Check duplicate IDs, missing values, and calculations  |
| Charts            | Visualise sales performance                            |
| KPI reporting     | Summarise key business metrics                         |
| Business analysis | Translate analysis questions into recommendations      |

## Key Performance Indicators

* Total Revenue
* Total Profit
* Number of Orders
* Average Order Revenue
* Overall Profit Margin

## Analysis Areas

### 1. Regional Performance

Compare revenue and profitability across geographical regions.

### 2. Product Profitability

Compare revenue and profit across product categories.

### 3. Sales Channel Performance

Evaluate online, retail, and corporate sales.

### 4. Data Quality

Check for duplicate transaction IDs, missing values, and inconsistent profit calculations.

## Business Recommendations

The analysis is intended to help management investigate:

* Opportunities to improve regional performance.
* Differences in profitability across product categories.
* The relative financial contribution of different sales channels.
* Opportunities to improve reporting accuracy.

Specific findings and recommendations should be based on verified Excel results.

## Project Files

* `sales_analysis.xlsx` — Excel workbook containing sales data and the dashboard.
* `sales_data.csv` — Synthetic source dataset.
* `business-recommendations.md` — Business analysis approach and recommendations.

## Limitations

The dataset is fictional and does not represent a real company.

It does not include operating expenses, returns, customer acquisition costs, or customer satisfaction data. These limitations should be considered before making real-world business decisions.

## Conclusion

This project demonstrates practical Excel skills and a structured approach to business analysis, from data validation to performance reporting and recommendations.
